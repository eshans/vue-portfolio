# Eric Shans Portfolio

Source for ericshans.com. Built with Vue 3, TypeScript, Vite, and Tailwind CSS.

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check and build to dist/
npm run preview  # serve the production build
```

- Skills, Work projects, and social links live in `src/data.ts`.
- Project screenshots are in `public/projects/`, skill icons in `public/skills/`.
